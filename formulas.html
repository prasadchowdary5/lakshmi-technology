Introduction to Excel Interface

Microsoft Excel is organized into several groups that help you perform different types of tasks efficiently.

FG Font Group

Controls text formatting:

  • Font type, size, color
  • Bold, italic, underline
  • Borders and fill color
  • Text effects and styles

AG Alignment Group

Controls cell content alignment:

  • Left, center, right alignment
  • Top, middle, bottom alignment
  • Text orientation and wrap text
  • Merge and center cells

NG Number Group

Formats cell values:

  • Number, currency, accounting
  • Date, time, percentage
  • Fraction and scientific formats
  • Custom number formats

CF Conditional Formatting

Automatically formats cells based on their values:

  • Highlight cells rules
  • Top/bottom rules
  • Data bars, color scales, icon sets
  • New rule creation
